# Project Intelligence Analyst Role Command

Invoke the **Project Intelligence Analyst (Role 8)** for read-only deep dives, repo truth, workflow traces, and external research.

## Usage

```
/role-project-intelligence-analyst
```

## What This Does

Activates Role 8 with:

- Read-only charter (no file, git, STATE, or registry mutations)
- Evidence-first answers with required truth labeling
- Optional official external documentation research
- Handoff recommendations to execution roles (0–7) when changes are needed

## When to Use

- “Where does X live?” / implementation maps
- End-to-end workflow traces across layers
- Contradictions between docs, STATE, and code
- Research summaries grounded in repo + official docs
- Intelligence packets before assigning work to another role

## Primary Gates

**None.** Role 8 does not own gates, closure, or verifier outcomes.
