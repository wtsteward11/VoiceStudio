### Bounded seam owners (not extension buckets) — Task 348

These types are **bounded seam owners**. They are **not** extension buckets for unrelated shell behavior. If a change does not match the slice brief, it does **not** go into an existing bridge.

**Standing review checklist (PR / handoff):**

1. Does this PR add behavior to an existing bridge **without** a new bounded brief + tests? → **Reject** or split into a new slice.
2. Does a new or edited type reference **two unrelated** shell features (e.g. palette + catalog in one file)? → **Reject** or split seams.
3. Does **`MainWindow`** regain inline logic that belongs in a **chartered** bridge? → **Reject** unless the brief explicitly moves it back.
4. Does the widened **GAP-008 `dotnet test` filter** (canonical list in [`tools/gap008_mainwindow_regression_filter.txt`](../tools/gap008_mainwindow_regression_filter.txt)) shrink or drop prior slice test tokens? → **Reject** — extend only; keep regression spine.
5. Does the change touch **`engines/audio/rhvoice/`** during a GAP-008 shell batch without operator proof? → **Reject** (RHVoice frozen in lane).
6. Does the change copy **`StatusBarCoordinator`**’s **`IStartupStateService.StateChanged` → `UpdateActivityIndicators`** pattern for **unrelated** shell UI? → **Reject** — that wiring is **status primary-line truth only** ([startup truth brief](VOICESTUDIO_BOUNDED_GAP008_STARTUP_TRUTH_RECOVERY.md) § Operator proof); not a generic broadcast-refresh architecture.
