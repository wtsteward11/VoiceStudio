# v1.1.0 Release Criteria (Item 40)

**Purpose:** Hard gates for declaring v1.1.0 release-ready (content-creator wedge).

## Hard gates (all must pass)

1. **Wedge workflow E2E**  
   The content-creator wedge workflow passes the end-to-end test: import WAV → apply podcast (or broadcast) preset → synthesize with Piper → export → output file exists and meets loudness target where applicable.  
   - Artifact: `tests/e2e/test_content_creator_workflow.py` passes in CI (or documented manual run).

2. **Consent enforcement**  
   Voice cloning and synthesis that use third-party reference audio require a valid consent record; otherwise the API returns 403 with an explicit error message.  
   - Artifact: Consent routes and runtime checks in place; manual or automated test confirms 403 when consent missing.

3. **Support bundle**  
   Support bundle exports cleanly and includes: last N API calls (from backend telemetry if available), engine manifest snapshot, hardware info, sanitized project state, build version.  
   - Artifact: `scripts/collect-support-bundle.ps1` (and any C# DiagnosticExport) produces a bundle; doc or checklist confirms contents.

4. **Installer size**  
   Installer (or runtime bundle) is within the documented size budget (e.g. ≤ 300MB); if over, optional components are identified and documented (e.g. download-on-demand).  
   - Artifact: `docs/reports/INSTALLER_SIZE_AUDIT.md` filled with actual sizes; budget and exceptions documented.

5. **Crash recovery**  
   All three crash-recovery scenarios pass: corrupt project file (graceful error), partial output file handling, crash marker path check.  
   - Artifact: `tests/e2e/test_crash_recovery_scenarios.py` (or equivalent) passes; doc in `docs/testing/UPDATE_SCENARIOS.md` if applicable.

6. **Beta usage**  
   At least 10 beta testers have used the application for 2+ weeks (self-reported or via local usage instrumentation).  
   - Artifact: Sign-off or usage evidence; no PII required.

## Sign-off

Before release:

- [ ] All six gates above verified.
- [ ] No known regressions in wedge workflow or consent.
- [ ] Release notes and changelog updated for v1.1.0.
